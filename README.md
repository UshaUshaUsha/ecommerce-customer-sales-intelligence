# E-Commerce Customer Sales Intelligence

## Project Overview

End-to-end analysis of an e-commerce retail dataset to identify
sales trends, customer behavior, high-value customers, churn risk,
retention patterns, and customer segments.

## Tools & Technologies

- Excel
- SQL / MySQL
- Python
- Pandas
- NumPy
- Scikit-learn
- K-Means Clustering
- Churn Prediction
- Cohort Analysis
- Power BI

## Project Workflow

### 1. Data Cleaning
- Removed duplicate transactions
- Handled missing product descriptions
- Identified missing customer IDs
- Created Revenue feature
- Checked negative quantities and cancelled transactions

### 2. Sales Analysis
- Monthly revenue trends
- Top products
- Top countries
- Top customers
- Order analysis

### 3. Customer Analytics
- RFM analysis
- Customer segmentation
- K-Means clustering
- Customer Lifetime Value

### 4. Churn Analysis
- Defined behavioral churn
- Built classification models
- Evaluated Accuracy, Precision, Recall, F1 and ROC-AUC

### 5. Retention
- Customer cohort analysis
- Monthly retention analysis

### 6. Dashboard
Power BI dashboard covering:
- Revenue
- Orders
- Customers
- Product performance
- Country performance
- Customer segments
- Churn
- Retention

## Business Insights

The analysis helps identify:
- High-value customers
- At-risk customers
- Revenue-driving products
- Strong-performing countries
- Customer retention patterns
- Opportunities for targeted customer campaigns
